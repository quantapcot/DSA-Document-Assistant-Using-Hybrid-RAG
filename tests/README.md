# Kiểm thử

`unit/` kiểm tra từng module; `integration/` kiểm tra module/API kết nối với nhau;
`fixtures/` chứa đầu vào nhỏ, ổn định và kết quả mong đợi.

Mỗi owner chịu trách nhiệm kiểm thử phần mình; A3 phối hợp kiểm thử tích hợp.
Hiện chưa có test suite. Tạo thư mục này không có nghĩa kiểm thử đã được viết.
