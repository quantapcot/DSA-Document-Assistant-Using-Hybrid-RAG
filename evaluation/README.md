# Đánh giá — D1 và D2

`datasets/` là đầu vào có kiểm soát; `metrics/` là cách tính chỉ số;
`scripts/` điều phối chạy; `results/` chứa số liệu từng lần chạy;
`reports/` chứa báo cáo tổng hợp.

D1 phụ trách benchmark và ablation; D2 phụ trách red-team và safety.
Script hiện còn rỗng, metrics chưa triển khai, chưa có kết quả đánh giá.
Ghi lại phiên bản code, cấu hình, corpus và dữ liệu đánh giá cho mỗi lần chạy.
