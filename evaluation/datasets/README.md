# Dữ liệu đánh giá

D1 chuẩn bị benchmark 30–40 câu hỏi kèm đáp án chuẩn và nguồn/chunk liên quan.
D2 chuẩn bị 20 testcase red-team theo phân công.

Khi có dữ liệu thật có thể dùng `benchmark.jsonl` và `redteam.jsonl`; chưa tạo
file trống giả làm dataset. Nhóm cần thống nhất schema, nhãn mong đợi và cách
quản lý phiên bản trước khi triển khai script.
