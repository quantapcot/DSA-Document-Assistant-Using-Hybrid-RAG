# Cấu hình thuật toán và thí nghiệm

Các file `.example.yaml` chỉ là mẫu thảo luận, chưa được ứng dụng đọc.
C1 sở hữu retrieval; C2 sở hữu generation; D1 ghi lại cấu hình trong thí nghiệm.
Khi tích hợp, nhóm cần thêm bộ đọc và kiểm tra cấu hình một cách tường minh.

Không lưu secret ở đây. Backend hiện đọc biến môi trường qua `app/core/config.py`.
